# 마나보 애드센스 준비

## 추가된 안내

- `/about/`: 사이트 소개 및 실제 학습 기능 안내
- `/privacy-policy/`: 현재 정보 처리 방식, 외부 리소스, 광고 도입 시 쿠키 안내와 맞춤 광고 설정 링크
- `/copyright/`: 자체 제작 콘텐츠와 외부 자료의 권리, 인용 및 재배포 안내
- `/contact/`: 운영자 연락처와 오류·저작권 문의 안내
- 모든 페이지의 푸터: 안내 링크 및 2026년부터의 저작권 표기

## 공개 전에 채울 정보

1. 공개 연락처는 운영자 곽신, 이메일 `no.type.shin@gmail.com`으로 반영되어 있습니다. 이메일 변경 시 문의 페이지와 개인정보처리방침의 HTML을 함께 갱신합니다. 빌드 환경 변수 `VITE_CONTACT_EMAIL`로 화면의 이메일을 재정의할 수도 있습니다. 이 값은 방문자에게 공개되는 연락처이므로 비밀값을 넣지 않습니다.
2. Cloudflare Workers 이용 사실과 Cloudflare 개인정보처리방침 링크를 반영했습니다. 접속 기록의 보관 기간은 확인되지 않은 숫자를 기재하지 않고, 서비스 설정 및 제공업체 정책에 따름을 안내합니다.
3. 운영자는 외부 콘텐츠를 가져오지 않았으며, 학습 이미지는 AI 도구를 활용해 직접 기획·제작했다고 확인했습니다. 소개와 저작권 안내에 제작 방식을 반영했습니다. 사용한 AI 서비스의 이용 조건과 글꼴 라이선스는 실제 서비스 및 파일 기준으로 관리합니다.

## 애드센스 연결 시 필요한 작업

1. 실제 공개 도메인으로 AdSense 사이트 등록 및 심사를 진행합니다. 안내 페이지 추가만으로 승인이 보장되지는 않습니다.
2. 계정에서 발급된 실제 게시자 ID와 광고 코드를 사용해 사이트 연결을 진행합니다. 현재는 광고 코드를 삽입하지 않았습니다.
3. AdSense에서 안내하는 실제 게시자 정보로 `public/ads.txt`를 작성하고, 배포 후 `/ads.txt`에서 제공되는지 확인합니다. 임의의 ID나 예시 값은 게시하지 않습니다.
4. 광고가 활성화되면 개인정보처리방침의 “현재 광고 코드가 연결되어 있지 않음” 안내를 실제 상태와 적용일에 맞게 수정합니다. 사용하는 광고 제공업체 및 방문 분석 서비스가 늘어나면 관련 처리 정보도 추가합니다.
5. EEA·영국·스위스 방문자에게 광고를 제공하는 경우 Google 인증 CMP 등 적용되는 Google 동의 요구사항을 확인하고 설정합니다. 개인정보처리방침의 맞춤 광고 해제 링크만으로 동의 절차를 대신할 수 없습니다.

## Google 공식 참고 문서

- 개인정보처리방침의 광고 쿠키 고지: https://support.google.com/adsense/answer/1348695?hl=ko
- 동의 관리 플랫폼 설정: https://support.google.com/adsense/answer/7670013?hl=ko
- Google 인증 CMP 요구사항: https://support.google.com/adsense/answer/13554116?hl=ko

빌드 명령은 기존과 동일하게 `npm run build`, 배포 폴더는 `dist`입니다. Vite의 여러 HTML 진입점을 사용해 각 안내 페이지의 내용이 빌드된 HTML에도 포함됩니다.

## 학습 페이지와 광고 운영 시작안

- `/kanji/`: 한자 도감
- `/reading/`: 한자 독해
- `/quiz/`: 한자 문제
- `/`는 기존 도감 진입점을 유지합니다.
- 학습 페이지 HTML은 `scripts/study-pages.mjs`가 공통 `index.html`에서 생성합니다. 생성 파일을 직접 편집하지 않습니다.
- 첫 방문 팝업 대신 각 페이지의 짧은 학습 안내를 제공합니다.
- 초기 광고 배치는 도감과 독해에 각각 1개부터 검토하며, 문제 풀이와 상세 정보 팝업·안내 페이지는 제외하는 것을 권합니다. 이는 시작을 위한 운영 제안이며 Google이 정한 광고 수 기준이 아닙니다.
- 사이트 인증은 실제 계정의 메타 태그 또는 코드로 진행하고, 광고 게재 전 개인정보 안내 및 필요한 동의 관리 설정을 실제 상태에 맞춥니다.
- 광고 개수와 수익은 비례한다고 가정하지 않고, 페이지 RPM·총수익·광고 가시성 및 이용자 경험을 비교합니다.
