# 학습 데이터 동기화 검증

`npm run sync-data`는 다음 검증을 모두 통과한 뒤에만 한자·독해 JSON을 교체합니다.

- 한자 최소 2,000개, 기존 파일 개수의 90% 이상 유지
- 한자·훈음·훈·학년·풀이·이미지 주소는 비어 있지 않은 문자열
- 한자는 한 글자이고 공백을 제거한 값 기준으로 중복 없음
- 학년은 초등학교 1~6학년, 중학 1~3, 고교 1~3 또는 참고
- 등급은 JLPT N1~N5. `참고` 항목은 빈 문자열 허용
- 음은 문자열. `참고` 항목만 빈 문자열 허용
- 암기순·획수는 양의 안전한 정수
- 문부성 순서는 양의 안전한 정수. `참고` 항목은 빈 문자열 허용
- 이미지 1은 HTTP 또는 HTTPS 주소
- 기존 한자 JSON을 읽거나 배열로 해석할 수 없으면 중단

현재 기준 데이터는 2,324개이며, 참고 항목 188개의 빈 JLPT 등급을 정상으로 처리합니다.
의도적으로 전체 개수를 크게 줄이는 경우에는 변경 내용을 검토한 뒤
`scripts/sync-sheets.mjs`의 최소 개수·유지 비율 기준을 조정해야 합니다.
환경변수로 검증을 건너뛰는 기능은 제공하지 않습니다.

필드 검증과 개수 비교는 임시 파일 생성 및 기존 파일 교체 전에 실행됩니다.
이미지 URL의 형식만 검사하며, 이미지 파일 다운로드나 원격 URL의 생존 여부 검사는 하지 않습니다.

검증 실행:

```sh
node --test scripts/sync-sheets.test.mjs
npm run build
```

CLI 회귀 검증은 임시 디렉터리와 대체 API 응답을 사용합니다.
실제 Sheets API나 프로젝트의 학습 JSON 파일은 갱신하지 않습니다.
