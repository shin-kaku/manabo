# 사이트 버그·성능 검토 — 2026-11-06

홈, 한자 도감, 독해, 퀴즈, 학습 자료, 모바일 화면과 이미지 처리 경로를 검토했다. 기존 글자 크기, 브랜드 색상, 획순 220px 크기와 배치는 유지했다.

## 수정 사항

| 확인한 문제 | 조치 |
| --- | --- |
| 홈에서 사용하지 않는 독해용 외부 폰트 CSS가 늦으면 본문 표시와 초기화도 지연됨 | 홈의 불필요한 폰트 요청 제거. 독해 페이지의 폰트는 유지 |
| 상세창을 닫거나 다른 한자로 교체한 뒤 이전 이미지 오류가 도착하면 Drive 대체 URL을 계속 요청함 | 이미 제거된 삽화·획순 이미지의 오류 처리 중단. 현재 열린 이미지의 대체 로딩은 유지 |
| 첫 방문의 모바일 상세창 위에 분석 동의 배너가 보이지만 `inert` 상태여서 누를 수 없음 | 상세창이 열린 동안 배너를 숨기고 닫으면 다시 표시. 동의 선택은 자동 변경하지 않음 |
| 정상 SVG의 `url("#clip")` 같은 내부 참조를 외부 리소스로 오인해 동기화에서 거부함 | 완전한 내부 참조를 허용하고 나머지 URL을 거부. SVG 원본 바이트와 애니메이션은 유지 |
| 여러 개발·검증 서버가 같은 HTML을 다시 생성하면 열린 페이지가 새로고침되어 스크롤 검사가 실패함 | 생성 내용이 같으면 파일을 쓰지 않음. 가상 스크롤 구현은 변경하지 않음 |

## 배포 전 검증

- 단위 테스트 **60개**, Chromium 브라우저 테스트 **69개** 통과.
- 브라우저 검사에는 빠른 스크롤과 DOM 수 제한, 화면 회전·포커스 복원, 검색, 독해·퀴즈, 테마, 루비, 미디어 대체 로딩 및 위 수정의 회귀 검사를 포함.
- 빌드 성공: 파일 **9,351개**, 미디어 **9,288개**. 배포 파일 수 한도 **20,000개** 이내.
- 빌드된 **39페이지 / 내부 링크 5,263개**에서 잘못된 경로·앵커 없음.
- 폭 **320 / 640 / 1280px**, 라이트·다크 모드에서 주요 9개 경로와 한자 상세 5개씩 확인: 문서 가로 넘침·상세 본문 넘침·실행 오류 없음.
- 로컬 획순 SVG **4,654개**가 수정된 검증기를 통과.
- 동일한 HTML **34개**를 재생성해 파일 변경 0개와 브라우저 새로고침 0회 확인. 회전·상세창 복원 검사 5회 연속 통과.
- `npm audit`: 알려진 취약점 **0개**. `git diff --check` 통과.

최초 전체 브라우저 검사의 1개 실패는 여러 서버의 HTML 재생성으로 발생한 개발 환경 새로고침이었다. 수정 후 안정된 환경에서 전체 69개가 통과했다. 실제 iPhone/Safari 기기 검증은 수행하지 않았으며, 네트워크 속도에 따른 모든 이미지 지연이 해소된다는 의미는 아니다. Google 원본과 공개 학습 데이터는 변경하지 않았다.
