## 관찰과 판단의 구분

공개 `/kanji/`와 `/ads.txt`는 HTTP 200이었고, ads.txt는 계정 게시자 ID와 일치했습니다.
따라서 이번 사유를 ads.txt 미인식 문제로 취급하지 않습니다.

기존 도감의 첫 HTML에는 카드 본문이 없고, 독해 HTML의 제목과 본문도 비어 있었습니다.
학습 내용은 JSON을 불러와 자바스크립트로 표시하며, 개별 독해를 직접 가리키는 주소가 없었습니다.
검색 로봇의 자바스크립트 실행 여부와 별개로, 이용자가 기존 고유 콘텐츠를 찾아 읽고 공유하기 어려운 구조였습니다.
이것이 거절의 직접 원인이라는 증거는 없으며, 아래 수정만으로 승인을 보장할 수 없습니다.

## 로컬 수정

1. `/materials/`에 학년별 한자 자료와 독해 전체 목록, 학습 방법을 연결했습니다.
2. 기존 2,324자의 뜻·일본어 읽기·암기 풀이·예시 단어를 **학년별 11개 문서**로 제공합니다. 한 글자마다 내용이 짧은 페이지를 만들지 않고 학습 범위로 묶었습니다.
3. 기존 독해 **19편 전체 본문**을 고유 주소에서 읽을 수 있게 했습니다. 기존 본문과 한자 자료 자체를 추가·수정하지 않았습니다.
4. 새 문서는 자바스크립트와 데이터 API 요청 없이 본문을 읽을 수 있습니다. 카드·검색·문제 풀이 기능과 연결됩니다.
5. 홈·사이트 안내·학습 화면에서 자료 모음으로 이동하며, 빌드한 사이트맵은 총 **39개 경로**를 포함합니다.
6. 독해가 일본어 원문이 아니라 **한국어 문장에 일본어 한자를 섞은 창작 암기 자료**임을 명확히 했습니다. 암기 풀이와 역사적 어원의 차이, 학년·JLPT 분류의 참고 성격도 안내합니다.
7. 정적 독해에서 해당 대화형 독해로 이동하고, 선택한 글을 새로고침해도 유지하도록 주소를 연결했습니다.

원본 Sheets 동기화, 이미지 교체, 광고 코드 삽입, 지급 정보 변경은 수행하지 않았습니다.
