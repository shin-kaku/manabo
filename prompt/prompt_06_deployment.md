# 작업: Vite 웹사이트 배포 준비 검사

현재 마나보 사이트를 실제 정적 웹사이트로 배포할 수 있는 상태인지 검사하고, 필요한 최소 수정만 수행하세요.

## 보호 조건

- 디자인을 재설계하지 마세요.
- 학습 콘텐츠를 수정하지 마세요.
- 백업 파일을 수정하거나 삭제하지 마세요.
- 회원가입·결제·Supabase 기능을 아직 추가하지 마세요.
- 검증되지 않은 대규모 리팩터링을 하지 마세요.

## 검사 및 작업 내용

1. `npm run build`가 성공하는지 확인하세요.
2. `npm run preview` 환경에서 사이트가 정상 작동하는지 확인하세요.
3. 새로고침 시 페이지가 깨지지 않는지 확인하세요.
4. 모든 정적 파일 경로가 `/` 또는 Vite 기준으로 올바른지 확인하세요.
5. 개발용 코드와 사용하지 않는 Vite 예제 파일을 확인하세요.
6. 브라우저 콘솔 오류를 확인하세요.
7. 모바일·태블릿·PC 레이아웃을 확인하세요.
8. 이미지 실패 시 대체 처리가 있는지 확인하세요.
9. HTML에 다음 기본 정보를 점검하고 필요한 경우 추가하세요.
   - 페이지 제목
   - 설명
   - 언어
   - 파비콘
   - 공유용 제목과 설명
10. 검색엔진 차단 설정이 잘못 들어 있지 않은지 확인하세요.
11. `dist` 폴더에 백업 HTML과 내부 작업 파일이 포함되지 않도록 확인하세요.
12. `.gitignore`에 최소한 다음 항목이 포함되는지 확인하세요.

```text
node_modules/
dist/
.env.local
.DS_Store
```

13. 배포 전에 공개되면 안 되는 값이 코드와 JSON에 들어 있지 않은지 검사하세요.

## 최종 검증

- `npm run build`
- `npm run preview`
- 도감·독해·문제 기능
- JSON 데이터 로딩
- 모바일 화면
- 직접 URL 접속과 새로고침
- 콘솔 오류
- 배포 파일 크기

## 완료 보고

- 실제 배포 가능 여부
- 수정한 파일
- 빌드 결과
- 주요 파일 크기
- 배포 전에 사용자가 준비할 항목
- Cloudflare Pages, Vercel, Netlify 중 현재 구조에 가장 적합한 서비스
- 해당 서비스에서 사용할 빌드 명령과 배포 폴더

실제 외부 서비스에 배포하거나 계정을 연결하지 말고, 배포 준비까지만 수행하세요.
