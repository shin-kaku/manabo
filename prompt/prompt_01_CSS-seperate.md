# 작업: 기존 단일 HTML에서 CSS 분리

현재 프로젝트는 Vite vanilla 프로젝트이며, 기존 마나보 웹사이트 전체가 `index.html` 한 파일에 들어 있습니다.

이번 작업에서는 CSS만 분리하세요. JavaScript와 JSON 데이터는 아직 분리하지 마세요.

## 보호 대상

- `index-v131-backup.html` 또는 이름에 `backup`이 들어간 파일은 절대 수정하거나 삭제하지 마세요.
- 현재 디자인, 반응형 화면, 문구, 기능, 데이터 구조를 변경하지 마세요.
- 새로운 라이브러리나 패키지를 설치하지 마세요.
- 요청 범위를 넘어 리팩터링하지 마세요.

## 작업 내용

1. `index.html` 안의 전체 `<style>...</style>` 내용을 `src/styles.css`로 옮기세요.
2. 기존 Vite 예제 CSS가 `src/styles.css`에 있다면 제거하고 마나보 CSS로 교체하세요.
3. `index.html`의 기존 `<style>` 블록을 제거하세요.
4. `index.html`의 `<head>` 안에 다음 CSS 연결을 추가하세요.

```html
<link rel="stylesheet" href="/src/styles.css" />
```

5. Google Fonts 연결은 현재 위치에 그대로 유지하세요.
6. CSS 선택자, 미디어 쿼리, 사용자 지정 속성, 색상, 크기와 여백을 임의로 수정하지 마세요.
7. 잘못 복사된 문자나 CSS 오류가 있는지 확인하되, 확실하지 않은 디자인 값은 바꾸지 마세요.
8. 기존 Vite 예제 파일이 현재 사이트에 영향을 주지 않도록 확인하세요.

## 검증

- `npm run build`를 실행하여 오류 없이 빌드되는지 확인하세요.
- 가능하면 개발 서버에서 다음을 확인하세요.
  - 한자 도감 화면
  - PC·태블릿·모바일 반응형 화면
  - 카드 뒤집기
  - 상세정보 창
  - 독해 페이지
  - 한자 문제 페이지
- 작업 전후 화면과 기능이 동일해야 합니다.
