# 작업: index.html의 실행 JavaScript 분리

CSS 분리가 완료된 Vite vanilla 프로젝트입니다.

이번 작업에서는 웹사이트 기능을 실행하는 JavaScript만 `src/main.js`로 분리하세요. 한자와 독해 JSON 데이터는 아직 HTML 안에 유지하세요.

## 보호 대상

- 이름에 `backup`이 들어간 파일은 절대 수정하거나 삭제하지 마세요.
- 기존 디자인, 문구, 데이터, 정렬 결과와 사용자 동작을 변경하지 마세요.
- 새로운 패키지를 설치하지 마세요.
- 이번 단계에서 기능을 새로 추가하지 마세요.

## 작업 내용

1. `index.html`에 들어 있는 스크립트 종류를 먼저 구분하세요.
   - 웹사이트 기능을 실행하는 일반 JavaScript
   - 한자 데이터가 들어 있는 `application/json` 스크립트
   - 독해 데이터가 들어 있는 `application/json` 스크립트
2. 실행 JavaScript만 `src/main.js`로 이동하세요.
3. `application/json` 형식의 한자·독해 데이터는 이번 단계에서 `index.html`에 그대로 두세요.
4. `index.html` 아래쪽에 다음 연결을 추가하세요.

```html
<script type="module" src="/src/main.js"></script>
```

5. 기존 실행 스크립트가 중복 실행되지 않도록 HTML에서 제거하세요.
6. 모듈로 변경하면서 HTML의 인라인 이벤트가 전역 함수를 참조하는지 확인하세요.
7. 인라인 이벤트가 있다면 기능이 깨지지 않도록 `addEventListener` 방식으로 변경하거나 필요한 함수만 명시적으로 연결하세요.
8. DOM이 만들어지기 전에 코드가 실행되지 않도록 확인하세요.
9. Google Sheets 연결, 저장 데이터 전환, 이미지 후보 처리 등의 기존 로직은 그대로 유지하세요.
