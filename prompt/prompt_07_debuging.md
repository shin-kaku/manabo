카드 내부 버튼의 키보드 조작 충돌
src/main.js:1052–1136, 1341–1360
카드 전체를 role="button"으로 만들고, 내부에 다시 button 요소를 넣었습니다. 카드의 keydown 핸들러는 이벤트 발생 대상이 카드 자체인지 확인하지 않습니다.
내부의 '한자 자세히 보기' 버튼에서 Enter 또는 Space를 누르면 이벤트가 상위 카드에 전달되어 preventDefault() 및 카드 뒤집기가 실행될 수 있습니다. 특히 키보드 사용자가 상세 보기 기능을 실행하지 못할 위험이 있습니다.
수정: 카드 핸들러에 e.target === card 조건을 적용하고, 가능하면 카드 뒤집기용 별도 버튼을 두어 중첩 인터랙션을 제거해야 합니다.



P1
손상·누락된 학습 데이터가 정상 동기화될 수 있음
scripts/sync-sheets.mjs · prepareKanji()
한자 데이터 검증은 비어 있지 않은 배열, 객체 여부, 한자 필드, 중복 한자만 검사합니다. 훈음·학년·등급·이미지 등 핵심 필드가 누락되어도 검증을 통과합니다.
예를 들어 Sheets API가 실수로 한자 한 개만 포함한 배열을 반환하면, 그것이 정상 데이터로 인정되어 기존 데이터 전체를 대체할 수 있습니다.
수정: 필수 필드와 타입, 유효한 값, 최소 데이터 개수, 기존 데이터 대비 급격한 감소를 검증하고 이상이 있으면 교체를 중단해야 합니다.
