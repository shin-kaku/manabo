## 처리 기준과 변경

- `持つ(もつ)`처럼 한자가 하나인 원문 예시에서는 앞뒤에 실제로 쓰인 가나로 경계를 확정하여 `持:も` 등의 어간 후보를 얻는다. 임의의 동사 활용형을 만들어 넣지 않는다.
- `㉫`에 있는 단어 전체 특수 독음을 해당 한자의 개별 독음으로 재사용하지 않는다.
- `先輩`, `一般`, `出発`의 반탁음과 `人々`, `津々浦々`의 반복 부호를 처리한다.
- 부족한 사전 행과 특별한 음변화는 293개의 검토된 단어별 항목으로 보완한다. 실행 중 외부 사전을 요청하지 않는다.
- `一人旅`는 `一人:ひとり + 旅:たび`, `虫眼鏡`는 `虫:むし + 眼鏡:めがね`로 분리한다. 원문이 가타카나인 `拉麺(ラーメン)`은 표시도 그대로 유지한다.
- 새 데이터의 독음이 불명확하거나 분할 후보가 여러 개면 전체 독음을 보존한다. 새 Google Sheets 데이터가 추가되었다는 이유만으로 테스트나 배포를 막지 않는다.
- 불가능한 읽기 조합을 반복 탐색하지 않도록 실패한 위치 조합을 기억한다.

## 그룹 유지 판단

남은 73개를 모두 언어학적으로 분할 불가능하다고 단정하지 않는다. `今日`, `七夕`, `秋刀魚`처럼 독음을 글자별로 배당하기 어려운 숙자훈과, 학습 자료에서 단어 단위의 특수 독음으로 취급하는 보수적 그룹 표기를 포함한다. 미검토된 일반 단어의 사전 누락을 방치한 목록이 아니다. 각 항목의 최종 경계는 아래 표와 보조자료에 명시했다.

[JmdictFurigana](https://github.com/Doublevil/JmdictFurigana)는 `大人`의 독음을 개별 한자에 임의 배분하지 않는 방식을 설명하며, 자동 생성 자료에는 오분할 가능성이 있다고 밝힌다. 따라서 자료를 통째로 채택하지 않고, 이번에 필요한 경계를 골라 검토했다. 예를 들어 원 자료의 `百:ゆ + 合:り`는 채택하지 않고 `百合:ゆり`로 남겼다.

`日本(にほん)`은 [漢字ペディア의 보통 음독 표기](https://www.kanjipedia.jp/kotoba/0005439300)를 참고하여 `日:に + 本:ほん`으로 분리했다. `天皇(てんのう)`도 `てん + おう`의 연성에 따라 `天:てん + 皇:のう`로 분리했다. 반면 [時計](https://www.kanjipedia.jp/kotoba/0002881900), [白髪](https://www.kanjipedia.jp/kotoba/0005609500), [景色](https://www.kanjipedia.jp/kotoba/0001793400), [尻尾](https://www.kanjipedia.jp/kotoba/0003567400), [河原/川原](https://www.kanjipedia.jp/kotoba/0004035400), [桟敷](https://www.kanjipedia.jp/kotoba/0002652000)는 사전의 특수 표기를 따라 그룹으로 유지했다. `芝生` 등은 [교육용 상용한자표 부표](https://gakusyu.shizuoka-c.ed.jp/japanese/syou_56/moji/04/fuhyou.pdf)에서도 단어 단위의 읽기로 제시된다.

`絵具(えのぐ)`는 표기에 없는 `の`를 어느 한 글자의 보통 독음으로 단정하지 않고 전체 그룹으로 남겼다. 실제로 쓰인 가나는 분리할 수 있으므로 `可愛い`의 `い`, `叔父さん`의 `さん`은 루비 그룹 바깥에 둔다.
